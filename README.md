Gobble Dash — Turkey's Great Escape: a turkey escape game. Thanksgiving is coming and the farmer is coming faster. Run 1500m from the farmyard, through the barn, past the kitchen oven, and out the forest gate. Dodge hay bales, fences, puddles, falling carving knives and the oven; grab corn to build your combo — and don't let the farmer catch you.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in desktop Chrome. SPACE / click to jump (twice for a double jump), DOWN to slide, SHIFT to dash, P to pause, M to mute. The hand-in program is `main.ts` (Node 22): `MAKEFUN_OUTPUT_DIR=out node main.ts`.
